# plotedge

Plot and reshape edge text streams with deterministic transforms.

**Site:** https://theworker02.github.io/plotedge/

## Install / run

```bash
git clone https://github.com/theworker02/plotedge.git
cd plotedge
node src/cli.js
node --test
```
